📖 Guia de Teoria Interativa

1. Estrutura e Tags HTML

O HTML organiza a estrutura de textos, links, imagens e blocos de uma página web.

<h1>Título da Página</h1>\n<p>Este é um parágrafo de texto.</p>

2. Estilos e Seletores CSS

O CSS colore, dimensiona e posiciona as tags HTML.

h1 { color: red; }\n.destaque { font-weight: bold; }

3. O Box Model

Content, Padding (interno), Border (borda) e Margin (externo).

4. Flexbox (display: flex)

Alinhe elementos facilmente na horizontal ou vertical com `justify-content` e `align-items`.

.container {\n display: flex;\n justify-content: space-between;\n}
